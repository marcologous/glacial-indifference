# Contributing to Glacial Indifference

Thank you for your interest in contributing to Glacial Indifference!

## Code of Conduct

By participating in this project, you are expected to uphold our [Code of Conduct](CODE_OF_CONDUCT.md). Please report unacceptable behavior to hankendesignco@gmail.com.

## How Can I Contribute?

### Reporting Bugs

If you find a bug or issue with the font:

1. Check if the issue already exists
2. If not, create a new issue with:
   - Clear title and description
   - Steps to reproduce
   - Expected vs actual behavior
   - Screenshots if applicable
   - Your environment (OS, software used)

### Suggesting Features

We're always looking for ways to improve! To suggest a new feature:

1. Open an issue with the `enhancement` label
2. Describe the feature and its use case
3. Explain why this would benefit the font community

### Pull Requests

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/your-feature`)
3. Make your changes
4. Ensure the font passes FontBakery checks
5. Commit with clear, descriptive messages
6. Push to your fork and submit a pull request

### Build Requirements

To work with the source files:

- **Glyphs** or **FontLab** for editing source files
- **fonttools** for building binary files
- **fontbakery** for quality checks

### Coding Standards

- Follow the existing design patterns in the source
- Maintain consistent naming conventions
- Test your changes thoroughly before submitting

## Recognition

Contributors will be recognized in the README and release notes.

## Questions?

Feel free to open an issue for questions about contributing.
